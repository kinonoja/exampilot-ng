# Phase 4.5 Stage 1: Source Notes

## Primary source

JAMB’s **Integrated Brochure and Syllabus System (IBASS)** presents programme categories including Administration, Agriculture, Arts/Humanities, Engineering/Environmental/Technology, Education, Law, Medical/Pharmaceutical Health Science, Sciences, and Social Management Science. It is the required final institution-specific validation source for the live product: [JAMB IBASS, brochure by programme](https://ibass.jamb.gov.ng/brochure-by-programme).

## Cross-check sources and extracted requirements

The reference dataset is a common-combination onboarding baseline, not a claim that each university uses one immutable combination. The detailed secondary pages consistently direct students to check JAMB’s brochure for institution-specific waivers or variations.

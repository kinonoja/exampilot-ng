# Mock Exam Format References

## JAMB UTME setup defaults for Phase 4 Sub-step 4a

ExamPilot’s JAMB full-mock setup uses the following publicly documented format: **four subjects**, comprising compulsory **Use of English plus three selected subjects**; **180 questions** total, with **60 English questions** and **40 questions for each other subject**; and a **120-minute** total duration.

This is used only for the full JAMB mock preset. A smaller practice-bank demo cannot construct a 180-question full mock until the required question-bank coverage exists, so the server will report any shortfall clearly rather than silently repeating questions or presenting an inaccurate mock.
